# top-10-gene-expression
Analysis of gene expression data using python
Gene Expression Analysis Using Python

Project Description

This project analyses a sample gene expression dataset using Python. The main objective is to identify the top 10 highly expressed genes.

Tools Used

- Python
- Google Colab
- Pandas
- Matplotlib
- GitHub

Dataset

A simulated sample dataset containing 15 genes and their expression values.

Methodology

1. Imported Python libraries.
2. Created and loaded the gene expression CSV dataset.
3. Sorted genes based on expression values.
4. Identified the top 10 highly expressed genes.
5. Created a bar graph to visualise the results.
6. Saved the results as CSV and PNG files.

Results

The top 10 genes were identified and displayed in a table and bar graph.

Conclusion

This project helped me understand basic gene expression data analysis using Python, Pandas and Matplotlib.

Note: The dataset contains simulated values for educational purposes.
